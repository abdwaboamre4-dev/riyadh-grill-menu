## 🌟 Overview

**RIYADH SMOKE & GRILL** is an ultra-premium, interactive VIP restaurant table reservation and digital menu web application inspired by world-class hospitality reservation engines (**SevenRooms** & **OpenTable**), specifically tailored for premier luxury venues in Riyadh — Al Takhassusi St, Riyadh.

### 🏆 Key Features

- **Autonomous Symmetrical SVG Brand Identity**: Stylized golden grill flame with royal smoke ring motif in #D4AF37 champagne gold finish.
- **SevenRooms-Style 4-Step VIP Reservation Drawer**:
  1. *Party Size, Date & Timeslot*: Interactive guest pills (1 to 12+ VIP), 14-day visual date picker with Saudi weekend badges, and 4 curated dining periods (Business Lunch, Sunset Golden Hour, Royal Dinner, Late Night Smokehouse).
  2. *Seating Zone & Live Floor Map*: 3 distinct luxury zones (Royal Main Hall, Panoramic Terrace, Private VIP Cabana) + visual table grid (T-01 to T-18) with real-time emerald available pulse and table reservation locking.
  3. *Occasion & Bespoke Amenities*: Anniversaries, birthdays, business dinners, family gatherings + custom chocolate celebration cake (+120 SAR) and luxury flower table arrangements (+180 SAR).
  4. *Guest Details & WhatsApp Concierge Dispatch*: Direct dispatch generating an itemized concierge booking confirmation with reference code sent directly to `+201104689702`.
- **10-Dish Digital Menu Catalog**: Uniform cards with verified high-resolution food photography, calories, prices in SAR, live search filtering, and best seller ember glowing animations.
- **Slide-Out Takeaway Cart**: Quantity increment controls, 15% VAT calculation, and WhatsApp takeaway dispatch.
- **Dual-Language Support**: Full seamless live switching between Arabic (RTL default) and English (LTR).
- **Mobile-First Responsive Design**: Optimized for mobile touch screens (375px–430px), `100dvh` viewport support, and iPhone home indicator `safe-area-inset-bottom`.
- **Live Reservation Ticker**: Periodic floating social proof notifications highlighting recent bookings.
